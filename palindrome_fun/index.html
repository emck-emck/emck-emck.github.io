Palindrome fun!


In 2022 I was playing around with a calculator, and I discovered that when an integer is subracted from its palindrome, the absolute result is divisible by 9.


In addition to this, when the process is repeated, one arrives at a palindrome number, which sets the subtraction equal to 0, ending the process.


For example, take the number "123".

123 - 321 = 198

198 / 9 = 22


22 - 22 = 0

0 / 9 = 0


I found this interesting, and wrote a program to systematically solve every number (up to the integer limit). I lost that program in a computer failure, so in 2026 I created this Javascript widget that helps demonstrate the concept.
